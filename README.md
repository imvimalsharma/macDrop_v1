# macDrop v1

An earlier version of **macDrop**, a file-transfer project for moving files from Android to Mac.

## 🎯 Purpose

This version represents an earlier implementation of the macDrop project and is kept separately from the newer version.

## Core Idea

- Android → Mac file transfer
- Multiple-file support
- File-name preservation
- Transfer progress
- Simple local file sharing

## 🚀 Getting Started

```bash
git clone https://github.com/imvimalsharma/macDrop_v1.git
cd macDrop_v1
```

Check the project files for the current setup and execution instructions.
